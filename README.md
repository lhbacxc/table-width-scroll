# Table Width Scroll

一个独立的 Obsidian 表格插件：拖动调整列宽、冻结前几列，表格可见区域始终限制在笔记正文宽度内，超出部分通过底部横向滚动条查看。支持阅读视图和编辑模式的实时预览（Live Preview），不改写 Markdown 表格。

## 功能参考与改进

本插件参考了 **Gridlock Tables** 的手动列宽调整功能，以及 **Table Style Tweaks** 的表格横向滚动功能，并做了以下改进：

- 将列宽调整和横向滚动整合到一个插件中。
- 表格可见区域默认与笔记正文等宽，超出部分在表格内部滚动查看。
- 在实时预览和阅读视图中提供一致的操作，并共用保存的列宽。
- 拖动时保持其他列的宽度，支持取消调整、重启恢复和重置默认布局。
- 冻结列参考 **Bases Freeze Panes** 的原生单元格 sticky 与 **Dream Table** 的多列偏移测量，保留普通 Markdown 表格格式。
- 默认冻结第一列，可按表格选择不冻结或冻结前 N 列，列宽变化时冻结位置同步更新。

## 安装

1. 下载并解压 [0.2.2 安装包 ZIP](https://github.com/lhbacxc/table-width-scroll/releases/download/0.2.2/table-width-scroll-0.2.2.zip)，更新内容见 [Release 说明](https://github.com/lhbacxc/table-width-scroll/releases/tag/0.2.2)。
2. 将解压出的 `table-width-scroll` 文件夹复制到 Obsidian 仓库的 `.obsidian/plugins/` 下。文件夹内直接包含 `main.js`、`manifest.json` 和 `styles.css`，避免多套一层文件夹。
3. 重新启动 Obsidian，或重新加载第三方插件列表，在「设置 → 第三方插件」中启用 **Table Width Scroll**。

更新已有安装时只替换上述三个运行文件，保留 `data.json` 中的列宽和冻结设置。0.2.2 修复实时预览左侧原生行六点手柄被滚动容器裁掉的问题，冻结后横向滚动仍可悬浮和选择行。

最低声明版本：Obsidian 1.14.4。实际使用的主题与其他表格插件组合，请按照 `./docs/verification.md` 中的操作清单验收。

## 使用

- 默认表格按正文宽度等分各列。很多列的表格保留每列至少 6ch 的默认宽度，通过滚动查看更多列。
- 将鼠标移动到表头右侧或任意行的列边界，拖动调整列宽。拖动一个列边界时，其余列保持原宽度。
- 超出正文的内容隐藏在表格滚动容器内。使用底部滚动条、触控板或触屏横向滑动查看。
- 默认第一列固定在左侧，表格上方不增加常驻控件。在实时预览中，右键列的六个点，菜单末尾的「冻结到此列」可冻结前 N 列；行菜单和普通单元格菜单也提供「冻结列设置…」。
- 「冻结列设置…」使用 Obsidian 的选择弹窗，支持跟随全局默认、不冻结和冻结前 N 列，可以用键盘搜索和选择。阅读视图在普通表格区域右键打开；链接和输入框继续使用原生菜单。
- 命令面板提供「设置当前表格冻结列」。同一视图存在多个表格且没有明确选择时，先选择表格，再选择冻结数量。
- 在插件设置页修改「默认冻结前几列」，0 表示不冻结；单独设定过的表格保留自己的选择。
- 冻结列数最多为总列数减一。窗口过窄或冻结列过宽时暂时减少生效数量，为滚动内容保留至少 48px 或可用内容宽度的 20%；实时预览的左侧行手柄空间单独保留。右键菜单显示数量受限提示，空间恢复后自动恢复原选择。
- 点击单元格仍可使用 Obsidian 原生表格编辑功能。
- 两种视图共用保存的列宽；重启和组件重新渲染后恢复。
- 双击表头的调整手柄，恢复当前表格的默认布局。
- 手柄可以通过 Tab 聚焦。左右方向键以 1ch 调整列宽，Shift + 方向键以 5ch 调整，Home 重置当前表格。
- 拖动期间按 Escape，或发生指针取消事件、窗口失焦、组件移除时，撤销这次未完成的调整。
- 命令面板中的「Table Width Scroll: 重置所有表格列宽」清除全部保存记录。
- 重置列宽只清除列宽记录，不改变冻结选择。「所有表格冻结列恢复全局默认」命令只清除各表格的冻结覆盖值，不改变全局默认和列宽。

「编辑模式」需要开启实时预览。源码模式显示 Markdown 文本，不显示可拖动的表格网格。

## 正文宽度与保存规则

插件不写死笔记宽度，也不扩大笔记正文容器。开启「缩减栏宽 / Readable line length」时，表格的可见区域跟随正文栏宽；关闭时跟随正文实际占用的宽度。内部表格在手动调宽后可以比可见区域更宽。

列宽以相对字体单位 `ch` 保存在 `.obsidian/plugins/table-width-scroll/data.json` 中，冻结列数和全局默认也保存在该文件，不改写 Markdown 笔记。列宽下限为 4ch，上限为 300ch。

插件不会添加 HTML、隐藏注释或专用代码块。其他支持 Markdown 表格的软件仍能读取原表格；列宽、冻结和滚动由目标软件自行呈现。单独复制 `.md` 文件不会带走插件设置。旧版数据缺少冻结字段时默认冻结第一列。

表格记录以笔记路径、源表头和相同表头的出现次数定位。普通正文修改、插入不同表头的表格，以及文件或文件夹改名后可继续恢复。更换表头后使用默认布局和全局冻结设置；列数改变时列宽回到默认，冻结数量按当前列数限制，但保留保存值。交换相同表头的表格顺序后需要重新调整。复制笔记到新的路径不会继承原笔记的列宽和冻结记录。

当前处理普通的顶层 Markdown 表格。引用、列表内嵌套表格和自定义 HTML 合并单元格不在本版的验证范围内。

## 设置

插件设置页提供全局启用开关和默认冻结列数。要在一篇笔记中停用，在属性中设置：

```yaml
cssclasses:
  - tws-off
```

## 开发与验证

在本文件所在目录使用 PowerShell 运行：

```powershell
npm ci
npm run build
npm test
npm run test:browser
npm run package
```

工程使用 Node.js，无 Python 或 Conda 依赖。Obsidian 与 CodeMirror 在编译时作为外部模块，运行时使用 Obsidian 自带的实现。

浏览器测试默认寻找本机 Chrome 或 Edge。如安装位置不同，可在运行测试前设置 `$env:TWS_BROWSER_PATH` 为浏览器可执行文件路径。

生产源码位于 `./src/`，设计及模块职责见 `./docs/design.md`，测试证据和真实应用验收范围见 `./docs/verification.md`。安装包中不包含测试工具或 Node.js 依赖。

开发前阅读[项目入门指南](./docs/onboarding.md)和[维护约束](./AGENTS.md)，了解数据流、修改位置及打包前的构建要求。
