# Table Width Scroll v0.1.0

本插件参考 Gridlock Tables 的手动列宽调整功能，以及 Table Style Tweaks 的表格横向滚动功能，将两者整合为一个独立插件。

## 相较两个参考插件的改进

| 参考功能 | 本插件的实现与改进 |
| --- | --- |
| Gridlock Tables 支持手动调整列宽，但默认允许表格向笔记正文之外扩展 | 保留手动调整列宽，将表格可见区域固定在正文宽度内，超出部分通过底部滚动条查看 |
| Table Style Tweaks 提供表格横向滚动，但不能手动调整列宽 | 在横向滚动的同时支持拖动列边界，整合到同一个插件中 |

- 实时预览（Live Preview）和阅读视图均支持列宽调整与横向滚动，两种视图共用保存的列宽。
- 拖动目标列时固定其他列，避免表格自动重新分配宽度。
- 表格可见区域跟随正文和分栏的实际宽度，无需写死笔记宽度。
- 保存列宽，切换视图、重新渲染和重启后恢复，不改写 Markdown 文本。
- 支持取消拖动、双击恢复默认布局、键盘微调，以及重置所有表格列宽。

## 安装

下载本 Release 的 `table-width-scroll-0.1.0.zip`，解压后将 `table-width-scroll` 文件夹放入 Obsidian 仓库的 `.obsidian/plugins/`，再在第三方插件设置中启用 **Table Width Scroll**。

ZIP 内仅包含 `main.js`、`manifest.json`、`styles.css` 三个运行文件。
