# Table Width Scroll v0.2.2

本版本加入冻结列与原生菜单设置，并修复实时预览中左侧原生行六点手柄无法悬浮显示的问题。表格继续在正文宽度内横向滚动，保留 Obsidian 原生单元格编辑，列宽和冻结设置不改写 Markdown 笔记。

## 主要更新

- 默认冻结第一列，每张表可选择冻结前 N 列、不冻结或跟随全局默认。阅读视图与实时预览共用保存的设置，重启和表格重新渲染后恢复。
- 通过原生行列右键菜单设置冻结；阅读视图支持表格右键，命令面板提供「设置当前表格冻结列」。表格上方无需常驻选择框。
- 修复左侧行六点手柄被滚动容器裁掉的问题：恢复悬浮显示、整行选择和原生行菜单，冻结后横向滚动仍可使用，手柄下方不再透出滚动列文字。
- 调整冻结区域的可用宽度计算。窗口过窄时临时减少生效列数，为剩余内容保留滚动空间；恢复窗口后恢复保存的选择。
- 保留列宽调整、取消拖动、键盘微调、跨视图同步和独立重置。升级兼容已有列宽与冻结数据。

## 安装与升级

1. 下载本 Release 附件 `table-width-scroll-0.2.2.zip` 并解压。
2. 将 `table-width-scroll` 文件夹放入 Obsidian 仓库的 `.obsidian/plugins/`，文件夹内直接包含 `main.js`、`manifest.json`、`styles.css` 三个运行文件。
3. 重启 Obsidian，或重新加载第三方插件列表，启用 **Table Width Scroll**。

已有安装只需替换上述三个运行文件，保留原来的 `data.json`，以保留列宽和冻结设置。

最低声明版本为 Obsidian 1.14.4。源码模式显示 Markdown 文本；表格交互需要实时预览或阅读视图。
