## 确认的行为

- 默认冻结第一列；全局默认数量可调整，每张表可跟随全局、不冻结或冻结前 N 列。
- 阅读视图与 Live Preview 共用记录，保留原生单元格和编辑组件。
- 只修改显示；冻结记录与列宽一起保存在插件 data.json，不添加 Markdown 注释、HTML 或专用代码块。
- 只冻结连续的前 N 列，至少保留一列可滚动。窄窗口保留至少 48px 或可见宽度 20% 的滚动区域，临时减少生效数量，保存的选择不变。
- 0.2.0 初版在表格顶部放置选择框；用户手动验收反馈它遮挡第一列原生手柄。0.2.1 改用原生右键菜单与选择弹窗，不保留顶部控件。
- 重置列宽不清除冻结记录；提供独立的全局冻结重置命令。

## 模块与数据

- `./src/freezeStore.ts`：冻结数量校验、全局默认与每表覆盖、路径改名和删除。
- `./src/freezeDom.ts`：原生单元格 sticky、实际偏移测量、尺寸变化与资源清理。
- `./src/freezeMenu.ts`：原生菜单显示前追加、阅读视图右键、选择弹窗和命令入口。
- `./src/tableDom.ts`：列宽应用后更新冻结位置，销毁时清理冻结装饰。
- `./src/resizeController.ts`：接入冻结配置、跨视图同步；冻结列拖动不叠加横向滚动补偿。
- `./src/main.ts`：加载和串行保存新字段、全局设置、重置及文件事件。

以上源码路径相对插件根目录。旧数据缺少新字段时默认冻结第一列；每表覆盖使用已有表格标识，显式 0 与无覆盖必须区别处理。错误数据被忽略，旧列宽格式继续兼容。

## 0.2.1 菜单入口优化

用户确认采用方案 1，在本地检查点 `285f152`（功能基本完成，待优化突兀的显示）之后继续开发，仍暂不推送 GitHub。

- 移除顶部控件。列六点菜单末尾增加冻结到此列、冻结列设置、不冻结和跟随全局默认；行菜单与普通单元格菜单提供通用设置。
- 阅读视图在普通表格区域右键打开冻结菜单；链接和输入控件继续使用原生右键行为。
- 设置当前表格冻结列命令支持键盘选择；多个表格且没有明确目标时先选表，不使用其他视图的焦点。
- 核对本机 Obsidian 1.15.0 原生实现：六点菜单使用 Menu.forEvent，不经过 editor-menu；普通单元格通过 editor-menu 接入。冻结组在 showAtMouseEvent 前追加，不在显示后重排。
- 只在当前 Menu 实例上适配 showAtMouseEvent 和 unload，不修改全局原型或调用原生表格私有编辑方法；关闭与卸载时恢复方法。
- Menu.onHide 是单回调槽，保留原生回调；内部重绘也调用 unload，以显示深度区别重绘和最终关闭。冻结项点击时核对表格标识，避免旧菜单修改新表格。
- 列宽控制器明确避开原生行列手柄及新增按钮，原生选择与移动保留所有权；冻结算法和 data.json 格式不变。

菜单接入方式独立实现；Good Tables 的公开源码仅用于调研原生菜单追加边界，没有复制其修改原生菜单 DOM 的逻辑。
