# Table Width Scroll 设计与实现计划

日期：2026-11-09。用户已确认按以下方案实现。

## 目标

新建独立 Obsidian 插件。表格可见区域跟随笔记正文宽度；列宽可拖动调整；表格内容超出可见区域时，通过底部横向滚动查看。阅读视图与编辑模式的 Live Preview 使用相同的列宽记录。源码模式显示 Markdown 文本，无法提供表格列边界。

## 实现方案

- 参考 Gridlock Tables 的原生表格增强、Pointer Events、CodeMirror ViewPlugin 与 MutationObserver。
- 参考 Table Style Tweaks 的表格容器横向滚动。保持 Obsidian 的正文宽度规则，滚动容器宽度为正文的 100%。
- 阅读视图使用原生表格所在的区块；Live Preview 使用原生 `.cm-table-widget`，不替换 CodeMirror 的表格组件。
- 表格初始按正文宽度等分列；列数太多时保留最小列宽，超出的列可滚动查看。
- 拖动前记录所有列的实际宽度；只更新目标列。使用 `ch` 保存，显式设置表格总宽度与各列宽度，避免自动布局挤压其他列。
- 列宽存入插件 `data.json`。以笔记路径、源表头和相同表头的出现次数标识表格，切换视图、重新渲染与重启后恢复。改表头或列数后使用默认布局；相同表头的表格互相换位后需重新调整。
- 松开指针保存；取消、窗口失焦、拖动期间组件被移除时撤销。同步更新同一表格在其他分栏中的显示。
- 启用/卸载时处理已有表格并清理插件自身的 DOM、事件、观察器与类名。

## 文件职责

| 路径 | 职责 |
| --- | --- |
| `./src/main.ts` | Obsidian 生命周期、视图接入、设置和保存 |
| `./src/livePreview.ts` | 编辑视图原生组件监听、源码位置映射 |
| `./src/tableDom.ts` | 滚动容器、列组、拖动手柄与恢复 |
| `./src/resizeController.ts` | 指针拖动、取消、键盘调整与跨视图同步 |
| `./src/tableIdentity.ts` | Markdown 表格定位和稳定标识 |
| `./src/widthStore.ts` | 列宽校验、记录、路径迁移 |
| `./styles.css` | 正文宽度约束、滚动条和手柄样式 |
| `./tests/` | 数据逻辑、浏览器布局和生命周期验证 |
| `./dist/table-width-scroll/` | 可直接安装的三个插件文件 |

## 验证与实施顺序

1. 创建 TypeScript 工程、许可证说明和设计记录。
2. 实现表格标识、存储、DOM 装饰、拖动控制与两种视图接入。
3. 编译生成安装文件。
4. 单元验证表格定位、列宽恢复与文件改名；浏览器验证宽度、横向滚动、拖动、取消、重复渲染和卸载恢复。
5. 写中文安装说明与验收记录，提供可安装的压缩包。

当前本机应用包中的 Obsidian 1.15.0 CSS 与两个参考插件中的容器结构已核对。浏览器模拟测试不能替代实际 Obsidian 的全部主题与插件组合测试；验收记录应明确区分两者。

## 设计检查

三个目标均由上述模块覆盖。默认宽度指可见容器宽度；内部表格可以更宽。正文宽度不写死。两个参考插件与新插件使用不同 ID 和类名前缀。派生代码保留 MIT 版权声明。
